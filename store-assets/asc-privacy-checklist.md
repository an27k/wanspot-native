# App Privacy（nutrition label）修正チェックリスト

App Store Connect APIキーが無いため手動更新用。
APIの `appDataUsages` は書き込み可能なエンドポイントが存在するが、キー無しでは実行不可。

根拠（2026-08-03 コード確認）:
- `lib/analytics.ts` は stub（Amplitude SDK 呼び出しなし。`app.config.js` にキー読み残しのみ）
- `expo-contacts` 未使用
- 広告は AdMob ネイティブのみ（`lib/prepare-search-ads.ts` の ATT + NPA フォールバック）
- 名前・メール・写真・検索履歴を広告/解析SDKへ渡す形跡なし

## 変更不要
| データ種別 | 方針 |
|---|---|
| 広告データ | 現状維持（AdMob） |
| デバイスID | 現状維持（AdMob / ATT） |

## 修正する
| データ種別 | 外す目的 | 残す目的 |
|---|---|---|
| 詳細な位置情報 | トラッキング / サードパーティ広告 / デベロッパの広告またはマーケティング | アプリの機能 / 製品のパーソナライズ |
| ユーザID | 同上 | アプリの機能 / 製品のパーソナライズ |
| 名前 | 全目的のうち広告・解析系 | アプリの機能 / 製品のパーソナライズ |
| メールアドレス | 同上 | アプリの機能 / 製品のパーソナライズ |
| 写真またはビデオ | 同上 | アプリの機能 / 製品のパーソナライズ |
| 検索履歴 | 同上 | アプリの機能 / 製品のパーソナライズ |
| クラッシュデータ | 全目的のうち広告・解析・マーケ | アプリの機能 のみ |
| パフォーマンスデータ | 同上 | アプリの機能 のみ |
| 製品の操作 | 同上 | アプリの機能 のみ |
| その他の使用状況データ | 同上 | アプリの機能 のみ |
| 診断データ | 同上 | アプリの機能 のみ |

操作場所: App Store Connect → アプリ → Appのプライバシー → 編集

## 年齢制限（ソーシャルメディア新設問）
現状のアプリには他ユーザーとの交流（フォロー/コメント/投稿フィード）もアルバム/VLOGも無い
（`REVIEW_ALBUM_TAB_ENABLED=false`, `VLOG_ENABLED=false`）。
バナーの設問文を読んで、該当しなければ「該当しない」系を選択。
設問文は未ログインのため本セッションでは未確認 → 手動で確認すること。
