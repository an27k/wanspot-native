## 1. 世界観と原則（全画面共通・最重要）

### プロダクトの正体
犬の飼い主向け「おでかけ×思い出」アプリ。VLOG機能は **SetLog×みてね型**:
- **SetLog**: 1時間に1回スロットが開き、最短2秒の動画を撮るだけで、1日分が自動で1本のVLOGになる
- **みてね**: 飼い主が上げる → 家族・実家の親が見て反応する → また上げたくなる、の往復ループ
- 世界観のメタファは **「うちの子のディスコグラフィー」**: Daily VLOG=毎日のシングル、
  Weeklyスペシャル=EP、誕生日=ベスト盤。アルバム棚（カバーフロー）に作品が並んでいく

### デザイン原則（飼い主視点）
1. **主役は常に犬**。UIは犬の写真・名前を引き立てる額縁。文言の主語は「モカ」（犬名）
2. **記録は義務にしない**。締切・カウントダウン・未達の赤バッジ・「撮り忘れ」表現は禁止。
   撮らなかったスロットは「ただ静かに空いている」だけ
3. **報酬は受け取り型**。「作りましょう」ではなく「できています」。ボタン文言は
   「見てみる」「受け取る」系
4. **ぬくもり×余白**。紙のような背景に、コーラルの体温。SNSアプリの喧騒ではなく
   「家族アルバムの静けさ」
5. トーンの参考: みてねの安心感 + SetLogの軽さ。キラキラ盛り系（SNOW等）にはしない

## 2. デザイントークン（実アプリから抽出。厳守）

### カラー
| 役割 | 値 | 用途 |
|------|------|------|
| brand primary | `#FB6B53`（コーラル） | 主ボタン・アクセント |
| brand dark | `#E85A42` | ボタン枠・押下 |
| accent | `#FF5E8A`（ピンク） | ハイライト・特別演出 |
| gold | `#FFB347` | ★評価・スペシャル装丁 |
| tint weak / strong | `#FFF0EC` / `#FFE3DA` | コーラルの淡面・主ボタン面 |
| **vessel** | `#1E1B19`（ダーク器） | **VLOGカード・プレビューの背景**（動画まわりだけ暗い） |
| text primary / secondary | `#2A2522` / `#7A726B` | 本文 / 補助 |
| surface paper | `#FBF7F2`（紙色） | 画面背景 |
| surface white | `#FFFFFF` | カード面 |
| border | `#EFE7DE` | ヘアライン |
| success | `#2FA56A` | 接種済スタンプ等 |
| sunset gradient | `#FF5E8A → #FF7E5F → #FEB47B` | **液体ゲージとアバターリングのみ**に使用可 |

### 形・質感の掟（v8 restraint）
- グラデーションは **sunset をアバターリング・液体表現のみ**。面には使わない
- 角丸: カード16px、ボタン16px、チップ999px（ピル）
- 影は最小限。紙色背景＋ヘアライン枠で層を作る
- アイコンは線画（Ionicons相当）。犬の肉球・骨モチーフは既存アイコンあり
- 全体は明るい紙色の世界で、**動画が絡む要素だけ vessel のダークで締める**

### タイポ・文言
- 日本語。ひらがな多め・やわらかく（「きょうのモカ」「おさんぽ」「おひるね」）
- 数字は控えめに。統計で誇示しない（「記録5日分」程度まで）
- 絵文字は文言に少量OK（🐾 🎬 ✨）。UIアイコンの代わりにはしない


## 4. 画面別詳細仕様

### 画面1: アルバムタブ・ホーム（撮影リズムの入口）★制作順1
**目的**: 1日に何度も開く場所。「いま撮れる」と「きょうの積み上がり」が一目で分かる
**レイアウト（上→下）**:
1. ヘッダー: 犬アバター（サンセットリング）＋「モカのアルバム」＋連続記録バッジ（「🔥3日」程度の控えめさ。ゼロの日は非表示、煽らない）
2. **スロットタイムライン（主役・高さ約100pt）**: 7時〜21時の横スクロール帯。
   - 撮影済みスロット=撮った動画の丸サムネイル＋タグアイコン
   - 現在スロット=コーラルのパルスする空枠「＋」（いま撮れる合図）
   - 過ぎた空きスロット=ごく薄いドット（存在感を消す。グレーの×や空白警告は禁止）
   - 未来スロット=さらに薄く
3. 撮影ボタン（大・コーラル面 `#FFE3DA`＋枠 `#E85A42`）:「いまの2秒をのこす 🐾」
   サブ文言は時間帯で変化（朝:「あさんぽ日和」/ 昼:「ごはんタイム？」/ 午後:「おひるね中…？」）
4. 完成報酬エリア（夕方以降のみ出現）: 画面4のカードがここに挿さる
5. きょうの記録リスト（時系列カード。タグアイコン＋気分スタンプ＋サムネ）
6. 下部: アルバム棚への入口バナー「これまでのモカを見返す ▶」（vessel ダーク面に小さなジャケット3枚が覗く）

**状態**: 記録ゼロの朝＝スロット帯は空でも温かく「きょうも、モカの2秒からはじめよう」。
夜に記録ありなら報酬カードが最上部に昇格

### 画面2: クイック撮影モーダル ★制作順2
**目的**: 起動から3秒で撮り終わる軽さ。「2秒だけ」の儀式
**レイアウト**:
1. フルスクリーンカメラ（縦）。上部に閉じる×のみ
2. 中央下: 大きな録画ボタン（押している間だけ録画、最短2秒。リング状に2秒の充填アニメ表現）
3. 録画ボタン上に**シーンタグチップ横並び**（おさんぽ🐾/ごはん🍚/おひるね🌙/おうち🏠/おでかけ☀️）。
   時間帯に合うタグが自動でプリ選択されている（ロジック実装済み）
4. 撮影後: 小さく気分スタンプ5種（ごきげん😄/はしゃぎ🎾/まったり☁️/おねむ😴/おいしい😋）→「のこす」ボタンで即完了
5. **「おでかけ」タグ選択時のみ**: 保存前に画面3へスライド遷移

**禁止**: フィルター・加工・美肌系UI（盛らない=SetLogの思想）

### 画面3: おでかけ分岐（スポット＋★メモ）★制作順3
**目的**: おでかけの2秒に「どこで・どうだった」を10秒で足す。ここがレビュー＝VLOG演出の源泉
**レイアウト**:
1. 上半分: いま撮った2秒のプレビューがループ再生
2. 「どこにいる？」: 現在地から近いスポット候補3件のカード（既存スポット検索を流用）＋検索
3. ★5段階（gold `#FFB347` の肉球スタンプでも可）
4. ひとことメモ（1行、placeholder「たのしかった！」）
5. 「のこす」ボタン。**スキップ可**（「あとで」リンク。義務にしない）
6. 補足キャプション:「★とメモはVlogに載ります 🎬」（この一言が動機づけ）

### 画面4: 完成報酬カード（Daily / Weeklyスペシャル）★制作順4
**目的**: 夕方18時の「できています」。E2=自動報酬の顔
**Daily版レイアウト**（ホーム内カード、vessel ダーク面で締める）:
1. 左: その日のベストカットが表紙のジャケット（小・立体感は薄く）
2. 右: 「きょうのモカのVlogができました 🎬」＋「9カット・約19秒」＋「見てみる」ボタン（コーラル）
**Weeklyスペシャル版**（日曜のみ。Dailyと同枠だが装丁が格上）:
- gold の縁取り＋「スペシャル」ピル。「記録5日分・おでかけ2スポット・ベストは★5の代々木公園ドッグラン」
- 微細な紙吹雪 or キラ演出1点まで（品を保つ）

### 画面5: VLOGプレビュー・共有 ★制作順5
**目的**: 再生して、家族へ・SNSへ。バイラルの出口
**レイアウト**:
1. 背景 vessel `#1E1B19` のフルダーク画面。中央に9:16動画（角丸12px）
2. 動画下: タイトル「きょうのモカ」＋日付
3. アクション行（左から）: 家族に送る（みてねの主動線・最左＝最優先）/ カメラロール保存 / SNSシェア
4. SNSシェア押下時: キャプション＋ハッシュタグのプリセットシート
   （「きょうはモカと代々木公園ドッグランへ 🐾 #wanspot #犬のいる暮らし #いぬすたぐらむ #犬とおでかけ #トイプードル」コピー済み状態）
5. 下部: 「アルバムの棚にならびました ✓」（保存の安心感）

### 画面6: アルバム棚（カバーフロー）★制作順6
**目的**: 夜・週末の「愛でる時間」。ディスコグラフィーの本体
**レイアウト**:
1. 背景は vessel ダーク（棚だけ夜の部屋の照明感。アプリ内で唯一のダーク常設画面）
2. 中央: カバーフロー。ジャケット（正方形・角丸8px）が立体的に流れ、中央の1枚だけ正面
   - ジャケット表紙=その日のベストカット写真
   - Weeklyスペシャル=gold縁取り＋「EP」感のある装丁 / 誕生日=ベスト盤装丁
3. 中央ジャケット直下: 日付（小・薄）＋題名「きょうのモカ」（16pt）＋メタ1行（🐾おさんぽ・ごはん ★5）
4. 再生ボタン「この日を見る ▶」
5. 下端: 月単位スクラバー（2026.5 — 6 — 7）で長距離ジャンプ
**掟**: 撮らなかった日のジャケットは存在しない（歯抜け表現禁止）

### 画面7: 家族サークル ★制作順7
**目的**: みてねの往復ループ。「見る側」（実家の親）にも迷わない画面
**レイアウト**:
1. ヘッダー: 「モカのかぞく」＋メンバーアバター横並び（飼い主/家族/見る側）＋招待ボタン
2. フィード: 新着記録・VLOGが時系列カード。各カードに**リアクションボタン（肉球スタンプ）**とコメント1行入力
3. Weeklyスペシャル完成カードは全員のフィード最上部にピン
4. 招待シート: 「家族を招待」（QR/リンク）。文言「モカの毎日を、いっしょに見守る家族を招待できます」
**配慮**: 見る側=高齢の親でも使える文字サイズ・タップ領域（最小44pt）

### 画面8: 動画内演出（9:16・1080×1920 レンダリングデザイン）★制作順8
VLOG動画そのものの中身。3カット分デザインする:
1. **イントロカード（1.5秒）**: 紙色背景に犬アバター（サンセットリング）＋「きょうのモカ」＋
   日付＋「3歳2ヶ月」。みてねの家族的な静けさで
2. **本編フレーム**: カット映像フル画面。左下にスポット名チップ（白ピル）、
   ★はgoldの小さな肉球、ひとことメモは下部1/4に手書き風字幕。
   右下に常時ウォーターマーク「wanspot · モカ 🐾」（不透明度75%・小さく）
3. **アウトロカード（1.5秒）**: 「モカのおでかけ記録は wanspot で」＋ストアバッジ＋QR。
   Weeklyスペシャル版は週間統計（記録5日分・スポット2件・ベスト★）を1画面に

### 画面9: マイルストーン演出（オーバーレイ）★制作順9
誕生日・記録100日目に画面1の最上部へ差し込むカード:
- 「モカ、お誕生日おめでとう 🎂」＋「これまでの思い出をVlogでふりかえりませんか？」
- gold基調・ベスト盤ジャケットのプレビュー付き。閉じるのは自由（押し付けない）

### 画面10: OS通知（文言＋見え方のみ）
- 撮影ナッジ（1日3回まで・実装済み文言）:「おさんぽの2秒、残しませんか 🐾」
- 完成報酬:「きょうのモカのVlogができました 🎬」
- 家族:「おかあさんさんがリアクション 💬」/「今週のモカ スペシャルVlog 🎬✨」
- 通知プレビュー画像に犬アバターを出す前提でデザイン

## 6. 禁止事項（全画面）
- 締切・カウントダウン・未達警告・「撮り忘れ」の可視化
- 面へのグラデーション多用（sunsetはリング・液体のみ）
- 盛り系フィルターUI・過剰なキラキラ
- 統計の誇示（週間ランキング・他人との比較）— 比べる相手は昨日のうちの子だけ
- 「ユーザー」という語。主語は犬名と「かぞく」
