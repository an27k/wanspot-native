対象デザイン: `Review Album Redesign.dc.html` の **4c（個別ページ）** / **5a→5b→5c（Vlog）**

## 1. スポット個別ページ（`app/spot/[id]` 相当）

### 構成（上から）

1. **ヒーロー写真** — 高さ ~290、ページャ `1/8`。左上 戻る（34px 円・白 90%）、右上 共有 `↗`
2. **タイトルブロック**
   - スポット名: 20px / 800
   - 評価行: `Gバッジ（白円+G青 #4285F4） ★4.5（コーラル 800） · 4件 · カテゴリ · 距離`
   - 評価行の右端: **外部リンク 2 個（必須）**
     - Instagram: 32px 角丸 10、グラデ `#F5B54A → #EC6FB0 → #9D8BF2`
     - Google マップ: 32px 白カード
3. **ワンスポ AI レビュー（必須）** — 背景 `rgba(251,107,83,.07)` 角丸 16
   - 見出し: `🐾 ワンスポAIレビュー` 11px / 800 `#C24B36`
   - タグチップ ×3（白地・`#C24B36`・nowrap）
   - 要約テキスト: 12px、`numberOfLines={2}`（全文は詳細展開）
4. **マップミニプレビュー** — 高さ 64 → タップでマップタブへ
5. **折りたたみ行** — `住所・営業時間・料金 ›`（白カード 1 行。本文は展開時のみ）
6. **下部固定アクション**
   - `♡ いいね`（白ピル・ラベル付き）
   - `🐾 行った`（コーラルピル・flex:1）
   - 「行った」は同日同スポット 1 回。多重タップガード
   - 成功 → ボトムシート（3b）: サムネ + スポット名 + `Vlogまで あとNスポット` + `★とメモをのこす` / `あとで`

### 禁止

- 住所・価格帯・AI 要約の全文を初期表示でベタ置きしない
- ヒーロー以外への全面グラデ（紙面のまま）

## 2. Vlog フロー（未来感の演出）

### 2-1. 生成中 — `VlogGeneratingPanel`（5a）

- 背景: `brand.vessel` フルスクリーン
- 中央: 犬アバター（104px、`GRADIENT_VLOG_LIQUID` リング 4px）
  - 外周オービットリング: conic-gradient（liquid）の細リング（2.5px）を **rotate 無限ループ**（Reanimated, 4s / linear）
  - さらに外側に同グラデの blur（14px）グロー、opacity .55 を **1.2s で明滅**
  - スパーク `✦` 2–3 個を軌道上に配置し回転に追従
- 見出し: `{犬名}の1日を編集中` 17px / 800 白
- 3 段階ステッパー: `✓画質解析（ミント） — カット選定（白/太） — レンダリング（白 40%）`。段階はサーバー進捗イベントで更新
- 進捗バー: 200×5px、fill は liquid グラデ。**不確定時は幅アニメで滑らかに**
- キャンセル不可。失敗時のみトースト + リトライ

### 2-2. 出力フォーマット（5b）— レンダラー仕様

- 1080×1920 / 10–35 秒
- BGM 3 曲から ★ 平均で自動選曲、120 BPM ビート同期

**INTRO 2s**

- `brand.vessel` 地に radial の liquid グラデ雲（ミント左上・パープル右上・ピンク右下、opacity .4–.5）
- 中央にアバター（グラデリング）→ 犬名 → `DOG VLOG`（等幅・letter-spacing .28em）→ 日付
- 要素は 0.2s ずつスタガーでフェードイン + scale 0.94→1

**CUT 2–4s ×N**

- 写真フル + Ken Burns（scale 1.0→1.08、パン方向は解析の顔位置優先）
- 左上: スポットチップ（白 92% ピル: `📍名前 ★4.5`）/ 日常ログは `🐾おさんぽ 😄`
- 下部: メモ字幕（下グラデスクリム `rgba(30,27,25,0→.65)`、白/700/中央）。**コンポーザーの字幕プレビューと同一スタイル**
- カット切替はビート頭にスナップ

**OUTRO 2s**

- INTRO と同系グラデ
- `また明日 🐾` + `{犬名} × wanspot` + 控えめウォーターマーク（右下、白 40%）

### 2-3. 最終確認画面 — `app/vlog/preview.tsx`（5c）

- 背景: `brand.vessel`
- ヘッダー: `✕ / きょうのVlog / 作り直す`
- 中央: 9:16 プレビュー（角丸 22）。**箱の外周に liquid グロー** `box-shadow 0 0 40px rgba(157,139,242,.25)`
- プレビュー内: 左上 `♪ 曲名 · 0:24` ピル、下部シークバー（fill=liquid グラデ）+ 再生ボタン + タイム
- CTA:
  - `↗ SNSで共有`（コーラル 52px）
  - `↓ カメラロールに保存`（白 10% ピル 48px）
- 保存成功 → ハプティクス + チェックアニメ。共有は mp4 ファイル共有シート
- 「作り直す」→ 5a に戻り再生成（選定シードを変える）

## 5. デザイン方針の補足（v8 restraint との関係）

| 文脈 | グラデ |
|---|---|
| スポット個別ページ（4c） | 紙面 UI。ヒーロー・外部リンクアイコンのみ例外 |
