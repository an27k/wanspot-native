```
ワンスポAIが仲間入りしました。

画面の右下にいる相棒に、いつでも話しかけられます。
「このお店、うちの子と入れる？」「この辺でテラス席のあるカフェは？」——
おでかけ先のことも、まとめ記事やイベントのことも、そのまま聞いてください。

・愛犬の名前やサイズ、いつものおさんぽエリアをふまえて答えます
```

## B. TestFlight 「テスト内容」（build 268 用）

```
ワンスポAIの動作確認をお願いします。

1. ログイン後、どの画面でも右下にキャラクターのボタンが出ること
2. タップして質問 → 3点ドットのあと、回答とカードが出ること
   （途中の「探してみますね」のような文章が出たり消えたりしないこと）
3. カードをタップ → スポット / 記事 / イベントの詳細が開くこと
4. 詳細から戻ってチャットを開くと、会話が残っていること
5. アプリを完全に終了して開き直しても、直近の会話が戻ること
6. 愛犬の名前で呼ばれること、前に話した内容をふまえた返事になること
7. ヘッダーの「…」から会話をクリアできること

情報が無いことを聞いたとき（例：マイナーな公園の足洗い場）に、
作り話をせず「持っていません」と答えるかも見ていただけると助かります。
```

## C. 提出前に必要なこと

### 必須

- [ ] **App Privacy ラベルの更新**（App Store Connect 上での作業。コードでは変えられません）
      チャットは会話の内容を保存するので、「ユーザーコンテンツ」→「その他のユーザーコンテンツ」を
      追加し、用途は「アプリの機能」＋「分析」、**ユーザーIDに紐づく**を選択します。
- [x] プライバシーポリシーへの記載（`src/app/privacy/page.tsx` に追記済み・デプロイ済み）
- [ ] 審査用メモ（App Review Information）に、AIアシスタントの説明を1〜2文入れておくと安全です。
      文案: 「本アプリのAIアシスタントは、当社が保有する犬同伴可否データベースにもとづいて
      回答します。回答には出典の種類（公式情報・掲載情報・推定）を示し、未確認の情報には
      その旨を明記します。」

### 確認しておくとよい点

- 審査は**ログインが必要**な機能なので、レビュアー用のデモアカウントが有効か
  （チャットは未ログインでは表示されません）
- 会話の保存について、アプリ内のチャット画面に「会話は品質改善のため保存されます」と
  表示済み（実装済み）
