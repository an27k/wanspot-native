# アルバム・カバーフロー構想 — 「うちの子のディスコグラフィー」

作成日: 2026-07-08
状態: **設計アイデアのみ（実装しない）**。VLOG実装フェーズのアーカイブUI候補として保存
関連: `docs/auto-vlog-engine.md`（自動生成エンジン）、`docs/setlog-vlog-improvement-proposal.md` E6（見返し）

## 1. 課題認識 — 「保存されたら価値が同じ」問題

VLOGやアルバムが平坦なグリッドに溜まっていくと、すべての思い出が等価に並び、
アーカイブの価値が日数に比例して薄まる。飼い主にとって「この日」はそれぞれ固有の
物語なのに、UIがそれを均してしまう。

**解**: 旧iPodのカバーフローのように、サムネイルを立体的なジャケットとして
ループさせるアーカイブUI。中央に来た1枚だけが正面を向き、日付と題名を携えて
「いま手に取っている」状態になる。指で繰る操作そのものが「レコード棚を漁る」
懐かしさの体験になり、「この日あったな」と直感的に降りてくる。

## 2. コンセプト — うちの子のディスコグラフィー

Daily VLOG が毎日1枚の「シングル」としてリリースされる世界観:

| 生成物 | 音楽メタファ | ジャケットの差別化 |
|------|------|------|
| Daily VLOG | シングル | ベストカットが表紙。タグの色味 |
| Weekly スペシャル | EP | 特別装丁（バッジ・箔押し感） |
| Monthly | アルバム | さらに厚み・背表紙 |
| 記念日・誕生日 | ベスト盤 | 周年装丁 |

飼い主の感情: **「見返したい」「集めたくなる」**。棚が伸びていくこと自体が
「うちの子と過ごした日々」の物量として誇らしい（コレクション欲＝継続動機）。

## 3. ジャケット生成ロジック（既存資産で完結する）

- **表紙**: その日のカットから `setLog.rankScore` 最上位を採用（既存の品質パイプラインを流用。
  「その日いちばんいい瞬間」が自動で表紙になる）
- **手前に出る情報**: 日付＋題名（「きょうのモカ」「海辺のカフェへ」）のみ。情報を盛らない
- **色味**: その日の主要タグ（おさんぽ/ごはん/おひるね/おうち/おでかけ）で
  ジャケットのトーンを変える → 棚を眺めるだけで「この週はよく出かけたな」が分かる
- **★の反映**: おでかけレビューの★はキャプション行に（★5 代々木公園ドッグラン）

## 4. インタラクション原則（飼い主視点）

- 横フリックで繰る。中央スナップ＋ハプティクス（クリックホイールの指触りの再現）
- 中央ジャケットをタップ → その日のVLOG再生（インライン）。もう一段タップで当日の全カット
- 長フリックで加速し月単位を飛ぶ（日付スクラバー併設）
- **空白日はジャケットを作らない** — 撮らなかった日は棚に存在しないだけ。歯抜けを見せて
  責めない（記録は義務にしない原則）
- 並びは時系列ループ。端まで行くと最初に戻る（「一生の棚」を巡回する感覚）
- 将来: ペットロス後の飼い主にとってこの棚は遺品級の資産になる。エクスポート・
  永続保存の設計はこのUIとセットで考える

## 5. 技術メモ（実現性の裏取りのみ）

- 既存スタックで実現可能: `react-native-reanimated` 4（scrollOffset → interpolate で
  rotateY / translateX / scale / zIndex）+ 中央スナップ、`expo-haptics`、
  サムネイルは既存 `memories.thumbnail_url`（署名URL）を `expo-image` で
- 反射・光沢まで欲しければ `@shopify/react-native-skia`（導入済み）で床反射をマスク描画
- パフォーマンス: 描画ウィンドウ±5枚程度、それ以外はプレースホルダ。低スペック機は
  回転を浅くしたフォールバック
- ロジック接点: 表紙選定は `lib/vlog-auto` に `pickJacketCut(plates)` を足すだけ
  （rankScore 最大値の1カット。実装フェーズで追加）

## 6. 位置づけ

アルバムタブの「見返しモード」。撮影リズム（スロットUI）が日中の入口、
カバーフローが夜・週末の「愛でる時間」の入口、という2つの顔を持たせる。
実装順は P1/P2（共有・BGM）→ 撮影リズムUI → カバーフロー を推奨
（棚に並ぶ「作品」が良質になってから棚を作る）。
