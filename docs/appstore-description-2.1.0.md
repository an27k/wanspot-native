■ Wanspotとは？

「今日のお出かけ、AIにきいてみる。」

愛犬と行ける場所を探して、行く前に確認して、そのまま家族や愛犬仲間とシェアできるおでかけアプリです。

wanspotは、ペット可スポット・ドッグイベント・お役立ち記事をひとつにまとめたアプリ。 カフェ・公園・レストラン・ホテルなど、愛犬同伴のスポットを地図から探せます。 「店内同伴」「テラス席のみ」といった確認できた同伴条件と、ワンスポAIレビューをひとつの画面で確認できます。

そして今、わからないことはそのまま聞けます。画面の右下にいるワンスポAIが、確認できた情報をもとにお答えします。

■ 主な機能

【ワンスポAIに聞く】 「このお店、うちの子と入れる？」「この辺でテラス席のあるカフェは？」 迷ったら、画面右下の相棒に話しかけてください。 愛犬の名前やサイズ、いつものおさんぽエリアをふまえて答えます。 おすすめはカードで表示され、タップすればそのままスポット・記事・イベントの詳細へ。 確認できた情報をもとにお答えし、わからないことは正直に「わかりません」とお伝えします。

【近くから探す】 今いる場所のまわりの愛犬同伴スポットを、地図にまとめて表示。 駅や地名で検索すれば、おでかけ前の下調べにも使えます。 カフェ、公園、レストラン、ホテルまで、全国47都道府県に対応しています。

【行く前に知る】 店内同伴、犬用メニュー、設備情報をAIが整理。 スポットごとにワンスポAIレビューが口コミを読み解いて要約し、お店に着いてから困ることを減らします。 写真、営業時間、Googleの評価、住所もまとめて確認。Googleマップやお店のInstagramにもワンタップで移動できます。

【ワンスポまとめ】 エリアやテーマ別の特集記事から、まだ知らないおでかけ先に出会えます。 ドッグカフェ、雨の日OK、お泊まりなど、眺めているだけで次の行き先が決まります。 記事の中から、気になったスポットへそのまま移動できます。

【イベントカレンダー】 マルシェやドッグイベントなど、愛犬と行ける予定を日付ごとにチェック。 開催日時・会場・料金・公式サイトへのリンクまで確認できます。 気になるイベントは、そのまま家族や友だちに共有できます。

【見つける。シェアする。一緒に行く。】 見つけたスポットやイベントを、ページごと家族や愛犬仲間に送れます。 共有された相手は、アプリを入れていなくてもWebですぐ内容を確認できます。 同伴条件や日時を一緒に見て、次のおでかけを決められます。

【愛犬プロフィール】 名前・犬種・サイズなどを登録。登録は約1分。 位置情報を許可すると、現在地の近くからすぐ探せます。 登録した内容は、ワンスポAIがうちの子に合わせて答えるときにも使われます。

■ こんな方におすすめ

・お店に着いてから「犬はちょっと」と言われた経験がある ・行く前に同伴条件を確認しておきたい ・調べるより、聞いて決めたい ・スポットもイベントも記事も、ひとつのアプリで済ませたい ・見つけた場所を家族や愛犬仲間とそのまま共有したい ・週末に行けるドッグイベントを見つけたい ・知らない街でも、近くから行き先を探したい

■ ログインについて

メールアドレスのほか、Apple・Googleのアカウントでもご利用いただけます。 ワンスポAIへの相談は、ログイン後にご利用いただけます。

■ お問い合わせ

ご意見・ご要望は support@wanspot.app までお気軽にお寄せください。 皆様のフィードバックを元に、より良いアプリへと進化していきます。

## 変更したところ

1. **冒頭に1文追加** — 「そして今、わからないことはそのまま聞けます。画面の右下にいるワンスポAIが、
   確認できた情報をもとにお答えします。」
   App Store は最初の数行しか展開前に見えないので、新機能をここに置きました。
   タグライン「今日のお出かけ、AIにきいてみる。」が、これで文字どおりの意味になります。

2. **【ワンスポAIに聞く】を主な機能の先頭に追加** — 今回の目玉なので最上位に。
   カードで提案してタップで詳細へ飛べること、わからないときは正直に言うことまで書いています。

3. **【愛犬プロフィール】に1文追加** — 「登録した内容は、ワンスポAIがうちの子に合わせて
   答えるときにも使われます」。登録する動機になり、かつ personalization の説明としても正直です。

4. **「こんな方におすすめ」に1項目追加** — 「調べるより、聞いて決めたい」。
   既存の項目は順序だけ整理し、文言は変えていません。

5. **ログインの節に1文追加** — 「ワンスポAIへの相談は、ログイン後にご利用いただけます」。
   実際にログイン必須なので、書いておかないと「使えない」という誤解につながります。
